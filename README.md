# YouTube.com Clone

A front-end clone of the YouTube homepage built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive header, sidebar, and video grid
- Keyboard-friendly navigation and skip link
- Search filtering and sidebar section filters
- Notifications panel toggle
- Voice search (supported browsers only)
- Data-driven video rendering

## Run Locally

- Open `index.html` in your browser, or
- Run `python -m http.server` in this folder and open `http://localhost:8000`, or
- Run `npm run dev` (uses `npx http-server` on port 5173)

## Tech Stack

- HTML5
- CSS3 (modular: `header.css`, `sidebar.css`, `video.css`, `general.css`)
- Vanilla JavaScript (`scripts/render.js`, `scripts/videos.js`)
